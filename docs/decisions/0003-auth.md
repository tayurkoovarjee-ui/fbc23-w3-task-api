# 0003 Passwords and tokens

**Passwords.** Argon2id through `argon2-cffi`, as the OWASP Password Storage Cheat Sheet recommends. Only the hash is stored and the hash never appears in a response.

**Tokens.** JWT signed with HS256 using `JWT_SECRET`, with a `sub` (user id) and an `exp` (60 minutes by default). The reader pins the allowed algorithm and requires `exp`, so a token with no expiry is rejected.

**Login errors.** A wrong email and a wrong password return the same 401 message. When the email is unknown, the service still verifies the password against a decoy hash, so the two cases also take about the same time.

**Other users' tasks.** Return 404, not 403. A 403 would confirm the task exists.

**Not done.** No refresh tokens, no logout, no rate limiting. They are outside the specification.
